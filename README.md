# CoCreate – Interactive Prototype

Open `index.html` in a browser (double-click or right-click → Open With → your browser).

Structure:
- `index.html`: Sign In
- `signup.html`: Sign Up (.edu email validation)
- `profile.html`: Profile creation (photo, skills, resume, basics)
- `home.html`: Home feed with projects, add/join, save, message
- `project.html`: Project details
- `matching.html`: Matching flow, suggested projects

Assets:
- `assets/css/styles.css`: Styles
- `assets/js/app.js`: Navigation and common logic
- `assets/js/data.js`: Sample users/projects data
- `assets/js/matching.js`: Skill matching logic

No build needed; it's static HTML/CSS/JS.
